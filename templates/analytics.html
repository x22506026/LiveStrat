Evidence and analytics

How LiveStrat strategies are validated, and what the evidence says.

Each strategy is tested with chronological splits, walk-forward folds, and multiple performance metrics. None of the methods peek at future data.

How strategies are validated

Four steps. Same standard for every strategy.

1

Chronological splits

Train, calibrate, validate, test. Time order respected. No future leakage.

2

Walk-forward folds

Model retrained on an expanding window. Each fold tests on data it never trained on.

3

Multiple metrics

Accuracy, balanced accuracy, macro-F1, Sharpe, max drawdown, excess vs hold.

4

Ablation

Data sources added one at a time to measure the actual contribution of each.

What these mean

Mean diff per bar
Average return advantage over buy and hold, per bar.
Bootstrap p
Probability the observed advantage is due to chance. Lower is stronger.
DM stat / DM p
Diebold-Mariano test for differences in prediction error.
Sharpe (ann.)
Annualised return per unit of volatility.
PSR
Probabilistic Sharpe Ratio. Probability the true Sharpe is above zero.
DSR
Deflated Sharpe Ratio. PSR adjusted for the number of variants tried.
Trials
Number of strategy variants used to deflate the Sharpe.
