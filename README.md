LiveStrat is a final year Data Science project that demonstrates how market data, sentiment signals and trading strategy ideas could be mixed into a one web platform. This repo contains a midpoint prototype focused on system architecture, data flow, and visualisation rather than proper trained ML models. All market, strategy and analytics outputs are simulated to show the intended behaviour of the final system.

How to run the prototype:
1. Python is installed
2. Install Flask:
   pip install flask
3. Run the application:
   python app.py
4. Open a browser and go to:
   http://127.0.0.1:5000/

Important notes:
- This is a prototype and a demo system.
- No trading, ML models, or databases are used at this stage.
- Login and signup pages demonstrate user flow only, you can insert any letters/numbers inside Username and Password field, press login you'll get directed to home page.
- Market, strategy, analytics, and notification outputs are demo logic
- Final examination will include full and better data visualisation, backtesting, and ML.
